# 生成异常后的复盘
输入：原始提示词、平台与模型（若知道）、实际结果（视频或关键帧）、用户期望。未看过视频时不下确定结论。

分级：P0 主体/故事/安全性错误；P1 机位空间/动作事件/身份连续性错误；P2 演技/节奏/声音；P3 微小穿帮。按严重性、修改成本、是否可后期修正排序。
诊断：`预期→实际→差异→可能原因(标置信度)→最小修改→预期副作用→检验办法`。优先一轮只改1–3处可判断变量；保留有效镜头；能剪掉的小问题不默认重跑。
典型纠正：
- “人物像雕塑”→眨眼、呼吸、视线目的、微小重心调整。
- “一直正对镜头”→物理机位、前景锚点、相对方向、参考图仅用于身份。
- “汽水喷太多”→明确几滴液体/一厘米泡沫的程度，而非“少量”独立用词。
- “道具突然换样子”→三视图 + 重复外观摘要 + 末态。
- “背景死”→具体路人各不相同的行为 + 远处车辆/风等。
- “动作机械”→把合理同步动作写“同时”，因果顺序写“随后”。

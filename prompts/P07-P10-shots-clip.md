# P07–P10：调度与CLIP

## P07 单镜导演调度七问（人填写或由助理引导）【教程提炼】
镜头{编号}，目的{想让观众知道或感受什么}：
1. 前景是什么、是否虚焦、声音？{ }
2. 前景在画面哪一侧？{ }
3. 背景是什么、是否虚焦、有什么动态？{ }
4. 拍摄主体是什么、站哪、朝哪？{ }
5. 机位：相机站在哪、角度、高度？{ }
6. 景别：远/全/中/近/特写，具体入画边界？{ }
7. 详细动作：谁先做什么、哪些同时、呼吸/眼神/重心、事件声音与台词？{ }
**扩展校验**：承接上一镜始态{ }，本镜末态{ }，光源{ }，镜头运动{ }，预期时长{ }。
先按七问确保导演想法完整；无必要不自动增加运镜。作者的七问与六个调度维度并非同一个清单。

## P08 人工调度专业化（发给AI助理）【教程提炼+本Skill扩展】
“你是导演助理。以下是我写的调度：{原文}。严格保留已写死的机位、空间、事件、动作、台词和节奏；将其转换为分镜结构：机位/景别/前景-主体-背景/人物站位/动作顺序与同时性/台词与声音/始态-末态。任何增加的内容标【体系补】，先单独列出，不未经同意混进锁定版本。检查空间矛盾、左右手变化、时间冲突、抽象情绪、无动感背景、前景缺失。用新手能懂的话解释每一项需修改的理由，输出完整可用的整理版。”

## P09 导演调度转CLIP（发给AI助理，非视频模型）【教程提炼+本Skill扩展】
“你是AIGC视频提示词工程师。输入：项目风格{ }、模型/平台{ }、参考图及各图职责{ }、上一条末态{ }、导演调度{ }、目标总时长{ }、画幅{ }。先在【校对说明】标出原文锁定点、【体系补】、空间或时间疑点、分镜时长建议。再单独输出**可完整复制的CLIP正文**，严格采用：
[STYLE LOCK] 固定视觉、光线、摄影物理、角色；
[参考图锚定] 逐张声明负责的身份、空间、道具，不自动承继参考图的机位；
[空间与站位声明] 明确相机、人物、道具、朝向、上段末态；
[CLIP主体] 按Shot逐镜详写前景/主体/背景、机位、景别、动作、同时与随后、微表情、环境动态、台词和事件声音，主体应占主要篇幅；
[BGM&声音设计] 氛围、音乐和事件声；
[NEGATIVE] 仅功能性必要禁令（通常3–8条）。
正文以正向物理事实为主，避免重复堆叠负向词。时间戳仅在模型支持或用户要求时强制，生成失真可提供不带时间戳版本。不得将校对说明混进CLIP正文。若模型不支持多镜头、多图或@引用，适配成可运行的单镜输入，并注明改动。”

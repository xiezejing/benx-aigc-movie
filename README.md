# benx-aigc-movie
AIGC影视创作与提示词优化 Skill，面向没有影视制作经验的创作者。

## 如何使用
将整个 `benx-aigc-movie` 文件夹置于支持 `SKILL.md` 的 Agent/工具的 skills 目录中；使用平台的技能添加方式载入。具体安装路径和启用方式因宿主软件而异。也可以直接把 `SKILL.md` 与相关 `prompts/` 文本提供给 AI 助手作为创作规则。

## 调用示例
- “使用 benx-aigc-movie，从一个创意带我做一条30秒广告，我是零基础。”
- “用 benx-aigc-movie 分析这张参考图，美术风格怎么形容？”
- “帮我把‘镜头拉近’换成正确的摄影表达，并优化视频提示词。”
- “把我手写的5个镜头调度转换成 CLIP，锁定原始动作。”
- “视频角色走路太慢，帮我分析并最小修改提示词。”

## 文件地图
- `SKILL.md`：主规则、按需加载入口。
- `workflows/`：从零、已有资产、返工修复。
- `prompts/`：P01–P12可复制模板，另含角色定妆照与多视角资产表模板（用户原创）。
- `references/`：新手术语、视觉鉴赏、任务索引。
- `examples/`：完整小白引导案例。
- `CHANGELOG.md`：版本化变更记录，管理本 Skill 的创作与迭代。

## 版本管理
本仓库采用语义化版本，变更记录见 `CHANGELOG.md`。
- MAJOR：规则结构或核心定位不兼容变更。
- MINOR：新增模板、流程、参考资料等能力。
- PATCH：措辞、路径修正与内容补全。

约定：
- 新增模块必须在 `SKILL.md` 的「源流标记」中标注来源（【教程提炼】/【本 Skill 扩展】/【用户原创 · benx】），并在 `CHANGELOG.md` 同步条目。
- 提交后打对应版本标签（如 `v0.9.0`），未发布的改动写入 `[Unreleased]`。
- 工作区是唯一源；发布时将整个目录同步到宿主的 skills 目录。

## 来源与限制
基础方法整理自用户提供的 Ksr桑教程笔记；扩展指导与模板是二次编排。并非原作者官方Skill，不含原作者未提供或未核实的专有脚本、模型支持声明。生成模型不保证绝对物理/人物一致性，建议以样片反馈为准。

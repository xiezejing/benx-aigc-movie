# 零基础专业术语教练【本Skill扩展】
## 回答格式：你说的 → 更准确的专业说法 → 白话解释 → 画面差异 → 可复制词
**不盲目纠错**：用户口语可以表达有效意图；只有会导致执行歧义时才纠正。一个请求优先解释最关键的1–3个概念。

| 用户表达 | 可能对应的专业术语 | 最关键差别 |
|---|---|---|
| 把镜头拉近 | 推镜 / 变焦推近 / 裁切放大 | 推镜改变透视与视差；变焦改变视角不改变机位；裁切损画幅 |
| 镜头左右扫过去 | 摇镜 pan / 横移 tracking | 摇镜原地转头；横移整台相机平行移动、前后景视差不同 |
| 很有电影感 | 光比、景深、色彩分离、运动节奏、构图、声音 | 需要指定可见/可听特征，避免空泛标签 |
| 人物很压抑 | 低调布光、遮挡构图、留白、俯拍（视目的） | 不是简单调暗；情绪取决于叙事语境 |
| 背景模糊 | 浅景深、焦点与散景 | 要指定焦点主体与虚焦背景，而非整体虚掉 |
| 大远景/全景/近景 | 景别 | 大远景重世界；全景见身形；近景见表情；特写见细节 |
| 对切两个角色 | 正反打 / 越肩正反打 | 越肩镜保留对方肩部，帮助空间关系 |
| 一口气从远到近 | 单镜头内推近 / 镜头切换 | 区分真实运动、数字缩放和剪辑切镜 |
| 慢慢变亮 | 曝光变化 / 灯光亮度变化 / 色温变化 | 是整体变亮、光源变亮，还是色彩变暖 |
| 节奏很快 | 镜头长度、动作频率、剪辑频率 | 快切不等于角色快速运动 |
| 音乐高大上 | 配器、织体、和声、动态、节拍、混音空间 | 指出希望由何种声音带来何种感受 |
| 声音切得突兀 | J-cut / L-cut / 声音交叉淡化 | J-cut：下一镜声音先进入；L-cut：上一镜声音延续到下一镜 |

## 专业门类速查
- **美术/视觉设计**：色彩搭配、材质、尺度、空间层次、视觉符号、时代一致性。
- **摄影**：景别、机位、镜头焦距、景深、视线方向、运动轨迹、照明动机。
- **导演**：调度、动作目的、角色动机、戏剧冲突、情绪弧线、信息揭示顺序。
- **剪辑**：镜头时值、动作匹配、轴线、节奏、J-cut/L-cut、声画对位。
- **声音/音乐**：画内/画外声、环境底噪、拟音、配器、节奏、调性、音色、声画动态。

## 初学者协作协议
用户写“主角很孤独，在大街，镜头有电影感”，先输出：
- 白话目标：“想让人看见主角被周围城市吞没”。
- 可选表达：“大远景、主体占画面约1/12；冷调街灯；前景行人交错而主角相对静止”。
- 解释：“大远景让观众先感受人和环境的距离”。
- 确认选择时用二选一：“想突出城市宏大，还是突出人物内心？”；用户已指明重点则直接做。

无法仅凭文字推断用户“真实审美”，不强制贴流派标签。音频无文件时不臆测实际音色/混音质量。

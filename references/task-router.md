# 任务路由：选对模板即可
| 用户想做什么 | 模板 | 输入 | 输出 |
|---|---|---|---|
| 整片画面应该是什么风格 | P01 | 主题、情绪、受众 | 2–3组可比较风格与生图词 |
| 先定街道、房间、建筑 | P02 | 地点、时间、摄影偏好 | 场景基准图词+固定项 |
| 创作主演 | P03 | 性格、外形、世界观 | 定妆照词+角色卡 |
| 人物/动物/道具的单张定妆或外观定型 | [用户原创定妆模板](../prompts/character-look-reference.md) | 主体类型、外观、材质、用途 | 生图提示词+固定项/可变项 |
| 根据定妆图生成五视图视觉资产 | [用户原创资产模板](../prompts/character-visual-asset-sheet.md) | 定妆参考图、固定特征 | 三幅身体＋两幅头部，或适配的结构与细节视图 |
| 一个人物多个角度 | P04 | 已有角色图 | 正/侧脸、正/背身四宫格 |
| 产品/道具每镜都一致 | P05 | 产品图片或文字规格 | 三视图+资产锁 |
| 写故事/情绪转折 | P06 | 主题、起终点 | 剧本、情绪曲线 |
| 具体怎么拍一镜 | P07 | 想传达的画面 | 七问调度 |
| 检查自己写的镜头 | P08 | 手写调度 | 保留版整理、缺口、建议 |
| 把调度交给视频模型 | P09 | 调度+参考图+模型 | 标准CLIP |
| 直接粘贴给视频模型 | P10 | 已确定的镜头、资产 | 视频模型输入正文 |
| 视频分几条生成 | P11 | 上一片段末态+下一片段 | 连续性声明 |
| 视频出了问题 | P12 | 原提示词+实际结果 | 问题定位+最小改动词 |

若用户只要“生成一张图”，不强制写剧本、调度、CLIP。若无参考图，先创作资产或声明仅文字锚定。支持先故事后美术或先美术后故事，不强行固定流程。
